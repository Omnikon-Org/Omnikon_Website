# Omnikon Logo & Asset Directory

Place your project, brand, partner, and community logos here:
**Path:** `/Users/pthawait/Documents/GitHub/Omnikon_Website/public/images/logos/`

### Supported Formats:
- SVG (`.svg`) - **Recommended** for crisp vectors at all resolutions
- PNG (`.png`) - Use transparent backgrounds
- WebP (`.webp`)
- JPG / JPEG (`.jpg`)

### Suggested Filenames:
- `omnikon-logo.svg` (Main community logo)
- `omnikon-icon.svg` (Square icon/favicon)
- `issueswipe.svg` or `issueswipe.png` (IssueSwipe project badge)
- `astrodex.svg` or `astrodex.png` (Astrodex project logo)
- `cntrl.svg` or `cntrl.png` (CNTRL project logo)
- `unvibe.svg` or `unvibe.png` (UnVibe project logo)
- `partner-gssoc.svg` (GirlScript Summer of Code)
- `partner-ecsoc.svg` (ECSoC)

### Usage in Code:
All files placed in this directory are served statically by Next.js at:
`/images/logos/<filename>` (e.g. `<Image src="/images/logos/omnikon-logo.svg" alt="Omnikon" width={40} height={40} />`).
